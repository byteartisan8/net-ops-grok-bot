# zabbix/ - Zabbix 8.0 monitoring of the lab (owner: session 04-zabbix)

Trap + poll monitoring of the PEs, **checked against NetBox**: every expected pseudowire (the NetBox spec, written into
each host as `{$NETSIM.PW.SPEC}`) is looked for on the device, so a PW that is missing or repointed is a problem, not
silence. A trap only makes Zabbix poll now ("traps are hints, polling is truth"). The business service tree (BSM)
is generated from NetBox, and every node carries its spec. Details, design and measurements:
[`docs/reports/04-zabbix.md`](../docs/reports/04-zabbix.md).

```
make zabbix-up          # build the 8.0.0rc1 images if needed (~7 min once), start, bootstrap (Admin password, API token)
make zabbix-provision   # template, hosts, trap action, BSM + SLAs + map from NetBox, dashboard (also part of `make seed`)
make zabbix-sync        # spec macros + BSM + SLAs + map from NetBox again (fast; 0 changes when nothing changed)
make zabbix-status      # BSM tree with statuses, current L2VPN problems, PWs per host
make zabbix-test        # unit tests (no containers)
make zabbix-test-integration   # against the running, provisioned lab: faults, NetBox changes, trap timings
```

UI: <http://127.0.0.1:8080> (user `Admin`, password `ZABBIX_ADMIN_PASSWORD` from `.env`), dashboard **L2VPN Services**,
map **L2VPN Topology**, Services → **L2VPN**. API: `http://127.0.0.1:8080/api_jsonrpc.php` (from labnet
`http://172.30.10.41:8080`), token `ZABBIX_API_TOKEN` (user `netsim-api`).

Python entry points (for lab-api, session 05):

```python
from netsim_zabbix.sync import sync  # after a (debounced) NetBox webhook; ~15-25 s when a spec changed
from netsim_zabbix.status import snapshot  # BSM tree + L2VPN problems + PW counts, as dicts
from netsim_zabbix.settings import load_settings

with load_settings().api() as api:  # ZABBIX_URL + ZABBIX_API_TOKEN (environment or .env)
    api.call("problem.get", {"tags": [{"tag": "scope", "value": "l2vpn-pw", "operator": 1}]})
```
